A full-stack real-time chat application that enables users to communicate through instant messaging. 
The application provides user authentication, real-time message delivery, and a responsive chat interface.
FEATURES-
User Registration & Login
JWT-based Authentication
Real-time messaging
One-to-one chat
Persistent message history
Responsive UI
Secure API communication
Tech Stack
Frontend: React.js, Redux
Backend: Node.js, Express.js
Database: MongoDB, Mongoose
Real-Time Communication: Socket.IO
Authentication: JWT
Project flow-
Frontend – Provides the user interface for authentication, conversations, and messaging.
Backend – Handles API requests, authentication, users, conversations, and messages.
Real-Time Layer – Uses Socket.IO to deliver messages and status updates instantly.
Database – MongoDB stores user information, conversations, and messages.
